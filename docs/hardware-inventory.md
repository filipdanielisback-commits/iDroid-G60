## Evidence format

For every update, record:
- exact Moto G60 model/region and board revision;
- source URL and date accessed;
- whether the information is from a primary source, device tree, kernel source, or community report;
- confidence level;
- unresolved questions.

Do not infer register addresses, GPIO numbers, firmware filenames, or memory ranges from another phone.
