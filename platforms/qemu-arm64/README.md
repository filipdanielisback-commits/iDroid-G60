# QEMU ARM64 research platform

Use QEMU's generic AArch64 `virt` machine for controlled experiments.

QEMU `virt` is not a Moto G60 hardware emulator. Success in QEMU does not prove XNU can boot on the phone or that any Moto G60 driver works.

Record QEMU version, exact command line, guest artifact hash, console output, and test result for every experiment. No bootable iDroid-G60 image is provided yet.
