# Boot research

This directory documents boot concepts and feasibility questions. It does not currently contain a phone bootloader, chainloader, or flashable image.

Research topics:
- ARM64 execution state and exception levels;
- firmware-to-kernel handoff;
- memory map ownership;
- device tree or other hardware-description handoff;
- secure boot and verified boot constraints;
- safe recovery planning.

Physical-device boot work is blocked until these topics are understood and independently reviewed.
