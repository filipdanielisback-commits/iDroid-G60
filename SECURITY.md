# Security Policy

This project is experimental and is not suitable for daily use.

## Reporting

Do not publish secrets, private keys, firmware dumps, personal data, or unpatched vulnerability details in public issues. Contact the repository maintainers privately through GitHub's supported security-reporting channel if one is enabled.

## Scope

The project currently has no supported device image or production boot chain. Security claims must not be made until a feature has been implemented, reviewed, and tested.
